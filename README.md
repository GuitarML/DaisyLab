# DaisyLab

This project is a work in progress and accompanies this [Youtube Video](https://youtu.be/a7t4HOnyYJc?si=x94Irn_ftIJcWl1D) for transforming a midi controller into a standalone instrument.

Includes KiCad hardware pcb and Gerbers, along with firmware for running synthesizers.

Currently requires modifying the daisy_petal.cpp and .h files before building libdaisy (modified files included in software/mod).
